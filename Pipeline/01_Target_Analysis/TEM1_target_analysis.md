# TEM-1 Omega-loop Target Analysis

## Target
- Protein: TEM-1 beta-lactamase

## Biological rationale
TEM-1 beta-lactamase is a major contributor to antibiotic resistance.

The Ω-loop (residues 164-179) contains the catalytic residue Glu166, which is involved in deacylation during catalysis.

## Structural analysis
Multiple class A beta-lactamase structures were aligned in PyMOL.

The Ω-loop was found to be structurally conserved across the selected structures.
